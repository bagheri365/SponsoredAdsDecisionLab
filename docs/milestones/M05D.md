# M05D — Reproducible synthetic pre-ranking experiment

## Purpose

Exercise the committed M05C `evaluate_cases` implementation with explicit labeled candidate groups, a documented missing-feature mechanism, and repeated phase timings. **This is an infrastructure experiment only**, not measured TaobaoAd ranking effectiveness.

## Run

```bash
python -m sponsored_ads.preranking_experiment \
  --seed 2026 --cases 20 --candidates-per-case 10 \
  --top-k 3 --missing-rate 0.1 --repeats 3 \
  --output artifacts/m05d/synthetic_report.json
pytest -q
```

The JSON report includes configuration, Python/NumPy versions, quality/coverage, per-case positive IDs and ranked IDs, and mean/p50/nearest-rank-p95 phase timings. Input generation and quality metrics are deterministic for a fixed configuration; timing measurements are **not** deterministic and depend on hardware and load. The output directory is not committed by default.

## Data and model provenance

- `synthetic_*` ad IDs and user IDs, synthetic category and brand, seeded random prices.
- Exactly one **random** positive label per case, chosen independently of model score and price. All candidate labels explicitly supplied; this is not negative sampling from real logged impressions.
- A fixed price-to-score function substitutes for a model, solely to exercise the M05A encoding and M05C evaluation interfaces. It is **not LightGBM**, trained CTR, or calibrated probability.
- Independently seeded missing price values exercise `missing_policy='skip'`. Unscorable positives remain in Hit@K/MRR denominators.
- Phase timings exclude retrieval, warmup, loading, I/O, network, and end-to-end serving overhead.

## Acceptance criteria

- Test suite passes; CLI emits parseable JSON.
- Re-running with identical inputs reproduces quality/coverage and per-case IDs, not necessarily timings.
- Reports explicitly state synthetic provenance and limitations.
- Record real terminal measurements separately in `docs/experiments/M05D-synthetic-results.md` only after running on the target machine; do not copy synthetic numbers into claims about TaobaoAd or online ads.
