# M05C — Labeled candidate ranking evaluation and profiling

## Scope

Adds `preranking_evaluation.py` with explicit `EvaluationCase` groups, per-case metrics, macro-averaged Hit@K/MRR@K, micro-aggregated feature coverage, and wall-clock phase profiling.

## Usage

```python
from sponsored_ads.preranking_evaluation import EvaluationCase, evaluate_cases

# index, model, contract, candidates, complete_rows, and binary_labels
# must come from explicitly documented sources.
case = EvaluationCase(tuple(candidates), complete_rows, binary_labels)
per_case, summary = evaluate_cases([case], index, model, contract, top_k=10)
print(summary)
```

`binary_labels` must include exactly one `0` or `1` for every candidate ID and at least one `1`. `missing_policy='skip'` reports unscorable candidates without excluding them from the ranking metric denominator. `missing_policy='error'` rejects incomplete rows.

## Interpretation

- `scorable / candidates` measures feature completeness before ranking truncation.
- Hit@K is 1 when at least one positive appears in the scored top K, otherwise 0.
- Reciprocal rank is `1 / first_positive_rank`, or 0 when none is in top K.
- Timing fields use `perf_counter` around assembly, inference, and sorting. They exclude artifact loading, candidate retrieval, network calls, and cold-start warmup.
- Tests use **synthetic** candidates, features, and labels. No measured Taobao ranking quality or latency benchmark is claimed.

## Limitations and next steps

Do not treat this module as an online/offline effectiveness result.
