# M07B-2: Deterministic scored-decision replay

Status: Locally verified; pending review and commit.

## Scope

- Add `decision_replay.py` with versioned, canonical JSON-compatible records.
- Replay recorded scored CTRs without model loading or inference.
- Reconstruct initial ledger state from budgets and prior ledger events.
- Compare decision, complete ledger event history, and account snapshots.
- Preserve provenance and detect unsupported versions, record changes,
  inconsistent results, and mismatched expected provenance.

## Acceptance criteria

1. Focused and full test suites pass locally.
2. A filled replay reproduces the decision and reserved budget.
3. No-fill cases create no additional event.
4. Prior ledger events are reconstructed before replay.
5. Tampering and inconsistent expected results are rejected.
6. A repeatable synthetic replay experiment is documented with actual hashes.

## Out of scope

Model re-execution, real billing, online performance, cryptographic signing,
feature materialization, distributed concurrency, and production event storage.
