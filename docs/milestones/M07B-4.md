## Acceptance criteria

- Both persisted-artifact pairs pass without model inference.
- Corrupt or mismatched reports, replay records, provenance, and supplied
  complete-file hashes fail with nonzero exit status.
- Existing M07A-3 report format and accepted embedded hashes are unchanged.
