# M06A-1 — Deterministic auction ranking contract

## Scope

Refactor M01 allocation to use a reusable immutable ranking result. The score
is CPC bid multiplied by predicted CTR; tie-breaking is lexical ad ID. Preserve
zero bids and duplicate-ID validation. No pricing, reserve, budget, or inferred
bids are introduced in this increment.

## Reproduce

```bash
pytest -q tests/test_decision.py tests/test_m06a1_auction_ranking.py
pytest -q
git diff --check
```

## Example

```python
from sponsored_ads.auction_ranking import rank_eligible
from sponsored_ads.models import AdCandidate

candidates = [
    AdCandidate('a', 'advertiser-a', predicted_ctr=0.10, bid_cpc=1.5),
    AdCandidate('b', 'advertiser-b', predicted_ctr=0.08, bid_cpc=2.0),
]
ranking = rank_eligible(candidates)
assert ranking[0].ad_id == 'b'
```

## Interpretation

This is a deterministic simulated allocation, not a real auction replay.
The M05B retrieval output does not include bids or advertiser identities;
callers must supply those fields explicitly, with documented provenance.
See `docs/adr/ADR-M06A-001-deterministic-auction-ranking.md`.
