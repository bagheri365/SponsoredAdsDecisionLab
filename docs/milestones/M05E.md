# M05E — Offline CTR calibration diagnostics

## Scope

Adds a standalone evaluation module for **already out-of-sample** click labels and predicted CTR probabilities. It fits sigmoid (logit-based Platt scaling) and isotonic calibrators on one stratified partition, then evaluates all three probability streams on a disjoint partition. Outputs Brier score, log loss, AUC, equal-width-bin ECE, and reliability-bin counts/means. The code does **not** save or serve calibrators; that is M05F.

## Usage

Input CSV must have precisely `clk,probability` headers and contain independent, held-out predictions, **not** in-sample predictions or the early-stopping set reused as an unbiased final evaluation set.

```bash
python -m sponsored_ads.ctr_calibration \
  --input artifacts/m05e/heldout_predictions.csv \
  --output artifacts/m05e/calibration_diagnostics.json \
  --seed 2026 --fit-fraction 0.5 --bins 10
pytest -q
```

No real-data experiment result is claimed until prediction provenance and data separation are documented. This command will fail if the input file has not been produced.

## Data constraints and next steps

The M03A development split is row-hash-based, neither temporal nor user-disjoint. M03B used the validation partition for LightGBM early stopping; its predictions must not be reused as a final unbiased calibration evaluation. The old M03B LightGBM `.txt` files currently lack the M05A `.contract.json` files required to reconstruct the fitted categorical mappings. Regenerate a matching model+contract bundle and reserve independent calibration and final evaluation rows before empirical reporting. The data contain observed impressions, not eligible inventories or counterfactual labels.
