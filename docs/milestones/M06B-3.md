# M06B-3 — Synthetic budget-aware auction experiment

Status: Implementation ready; full repository verification and local replay pending.

## Scope

Run a declared six-step synthetic auction sequence against shared advertiser budgets, separately for first-price and score-second-price policies. Each policy receives an independent fresh ledger with identical initial budgets and click flags. Each admitted winner is reserved and immediately finalized as an explicitly synthetic click or nonclick. Compare allocation, no-fill, budget exclusions, conditional CPC, settled cents, released hold, and final ledger balances. Replay the ordered ledger events and verify equality of snapshots and events.

## Reproduce

```bash
python -m sponsored_ads.budget_experiment --output artifacts/m06b3/synthetic_budget_auction_report.json
pytest -q tests/test_m06b3_budget_experiment.py
pytest -q
shasum -a 256 artifacts/m06b3/synthetic_budget_auction_report.json
python -m sponsored_ads.budget_experiment --output artifacts/m06b3/synthetic_budget_auction_report.json
shasum -a 256 artifacts/m06b3/synthetic_budget_auction_report.json
```

`report_sha256` is the SHA-256 of canonical JSON **excluding its own `report_sha256` field**; `input_sha256` hashes the canonical input specification. The file checksum hashes the full serialized report, including the embedded checksum. Canonical JSON uses sorted keys, compact separators, disallows NaN, and ends with a newline. Compare the two **file** checksums to verify repeatability in your environment.

## Limits

No observed bids, clicks, spend, auction revenue, user traffic, market effects, or causal lift. Click flags are fixed inputs, not generated from predicted CTR. Sequential immediate finalization deliberately avoids concurrent holds and delayed clicks. No pacing, persistence, multi-slot auctions, or actual billing. The ceiling-to-cent convention is conservative and may round a floating-point CPC by one cent.
