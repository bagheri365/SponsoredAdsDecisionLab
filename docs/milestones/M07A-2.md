# M07A-2 — Model-to-auction integration

Status: Pending local full-suite verification.

## Deliverables

- `FeatureCandidate`: complete M03A feature row, bid, IDs, eligibility.
- `load_model_auction_bundle`: reuse M05F-C artifact/contract compatibility checks and record SHA-256 provenance.
- `decide_with_model`: batch CTR inference, optional calibrated probabilities, existing M07A-1 auction and budget reservation.
- Failure atomicity tests for invalid features, predictions, duplicate IDs, and no-fill.

## Local verification

```bash
pytest -q tests/test_m07a2_model_auction_service.py
pytest -q
git diff --check
```

## Usage

```python
bundle = load_model_auction_bundle(model_path, contract_path, None, method='raw')
result = decide_with_model(request, feature_candidates, ledger, bundle,
                           policy='score_second_price', event_id='e1', reservation_id='r1')
```

Only use **complete M03A feature rows** with a compatible persisted model. Do not treat catalog-only records as complete inference features. The result is a synthetic, local auction decision, not online performance or revenue evidence.
