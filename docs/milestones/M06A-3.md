# M06A-3 — Reproducible synthetic auction experiments

Status: Implemented; local full-suite verification pending.

## Scope

`auction_experiment.py` runs eight **declared synthetic** scenarios with both M06A-2 pricing policies. Identical candidates and reserves are supplied to each policy. Allocation must agree; payment and expected-revenue proxies may differ. A reserve sensitivity pair changes only the reserve. No model fitting, dataset access, budgets, actual clicks, or settlement.

## Reproduce

```bash
python -m sponsored_ads.auction_experiment --output artifacts/m06a3/synthetic_auction_report.json
pytest -q
```

The output is deterministic JSON, includes a SHA-256 of the serialized synthetic inputs, and is intended to remain ignored under `artifacts/`. Re-running with the same code and inputs should produce identical bytes. `input_sha256` does not hash source code or dependencies; use the Git commit and environment to identify those.

## Interpretation

`conditional_cpc` is a simulated payment **only if a click occurs**. `expected_revenue_proxy_per_impression = predicted_ctr * conditional_cpc` is a model-based proxy, not observed revenue or realized charging. An unfilled auction has null conditional CPC and proxy rather than zero revenue. This experiment cannot estimate causal lift, true platform auction outcomes, or bidder incentives.

The two policies use the same ranking; their allocation agreement is a software invariant, not an empirical result. The finite synthetic scenarios are illustrative, not a population estimate.
