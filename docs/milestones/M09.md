# M09 — Portfolio release and interview readiness

## Goal

Freeze feature development after M08-1 and prepare a truthful, reproducible
portfolio presentation for a prospective ML engineer or ads-systems interviewer.

## Documentation deliverables

- [README](../../README.md) describing current capabilities rather than M01 plans.
- [Architecture overview](../architecture.md) separating observed-data ML,
  synthetic auctions, and offline verification.
- [Five-minute demo](../portfolio-demo.md) with no Taobao-data prerequisite.
- Explicit limitations and pointers to historical ADRs and experiments.

## Release gate (not yet executed)

1. Inspect this documentation diff and verify referenced commands and paths.
2. Test a fresh clone on Python 3.10+ with `pip install -e '.[dev,ml]'`.
3. Run `pytest -q`, `python -m sponsored_ads`, and the M08 synthetic demo.
4. Review generated metrics and hashes; document the *actual* release evidence.
5. Only then consider changing package version from `0.1.0` to `1.0.0`,
   committing release metadata, and creating/pushing an annotated `v1.0.0` tag.
