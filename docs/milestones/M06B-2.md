# M06B-2 — Budget-aware auction admission

## Scope

Integrate M06A allocation/pricing and M06B-1 budget reservations with an explicit **retry among affordable candidates** policy. Unaffordable candidates are excluded before repricing; budget sufficiency is measured against the *maximum bid*, not the conditional CPC. The implementation remains a deterministic, single-threaded synthetic simulation.

## Reproduction

```bash
pytest -q tests/test_m06b2_budget_admission.py
pytest -q
git diff --check
```

Example:

```python
from sponsored_ads.models import AdCandidate
from sponsored_ads.budget_ledger import BudgetLedger
from sponsored_ads.budget_admission import admit_budget_aware

ledger = BudgetLedger({'adv-a': 199, 'adv-b': 300})
result = admit_budget_aware(
    ledger,
    [AdCandidate('a', 'adv-a', 0.2, 2.0),
     AdCandidate('b', 'adv-b', 0.1, 3.0)],
    policy='score_second_price', event_id='e1', reservation_id='r1',
)
assert result.excluded_ad_ids == ('a',)
assert result.outcome.ad_id == 'b'
assert result.outcome.charged_cpc_if_clicked == 0.0
assert ledger.snapshot('adv-b').reserved_cents == 300
```

## Exclusions

No concurrency, real billing, pacing, click generation, persistent event storage, or statistically representative traffic. Do not interpret auction allocation, conditional CPC, or budget admission as observed market outcomes. Finalize simulated click/no-click separately through M06B-1.
