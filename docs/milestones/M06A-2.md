# M06A-2 — Single-slot synthetic CPC pricing

## Scope

Introduce explicit first-price and score-based second-price conditional CPC policies on top of M06A-1 `rank_eligible`. No change to `choose_ad`, CTR inference, candidate retrieval, or budgets.

## Example

```python
from sponsored_ads.models import AdCandidate
from sponsored_ads.auction_pricing import price_single_slot

ads = [
    AdCandidate('a', 'adv-a', predicted_ctr=0.2, bid_cpc=2),
    AdCandidate('b', 'adv-b', predicted_ctr=0.1, bid_cpc=3),
]
first = price_single_slot(ads, policy='first_price')
second = price_single_slot(ads, policy='score_second_price')
assert first.charged_cpc_if_clicked == 2
assert abs(second.charged_cpc_if_clicked - 1.5) < 1e-12
```

## Interpretation

`charged_cpc_if_clicked` is a hypothetical conditional charge in CPC currency units. It is **not** observed spend, platform revenue, an actual CPC, or evidence of causal auction lift. Inputs require explicitly supplied advertiser IDs, bids, and CTR policy. See ADR-M06A-002 for reserve, zero-CTR, and tie semantics.
