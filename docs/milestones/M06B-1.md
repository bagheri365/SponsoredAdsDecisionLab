# M06B-1 — Budget admission and accounting invariants

Status: Pending local validation.

## Scope

A deterministic, in-memory integer-cent ledger with explicit reserve, click settlement, nonclick release, duplicate event protection, and replay. It integrates with the existing `AuctionOutcome` but does not change M06A allocation or pricing. Reserve the winner's **maximum bid** before accepting the simulated auction outcome.

```bash
pytest -q tests/test_m06b1_budget_ledger.py
pytest -q
git diff --check
```

## Example

```python
from sponsored_ads.models import AdCandidate
from sponsored_ads.auction_pricing import price_single_slot
from sponsored_ads.budget_ledger import BudgetLedger, reserve_auction_winner, finalize_auction_winner

outcome = price_single_slot([
    AdCandidate('a', 'adv-a', 0.2, 2.0),
    AdCandidate('b', 'adv-b', 0.1, 3.0),
], policy='score_second_price')
ledger = BudgetLedger({'adv-a': 300})
reserve_auction_winner(ledger, outcome, event_id='e1', reservation_id='r1')
print(ledger.snapshot('adv-a'))
finalize_auction_winner(ledger, outcome, event_id='e2', reservation_id='r1', clicked=True)
print(ledger.snapshot('adv-a'))
print(BudgetLedger.replay({'adv-a': 300}, ledger.events).snapshot('adv-a'))
```

The float representation of score-based second-price conditional CPC is `1.5000000000000002`, conservatively rounded to **151 cents** at this simulation boundary. The 200-cent maximum bid is reserved before settlement; 49 cents of the hold is released at settlement. No click is generated by this code; `clicked=True` is an explicit synthetic event.

## Limitations

No pacing, concurrency, delayed clicks, refunds, persistence, actual spend, or claims about Amazon Ads' accounting. Insufficient-budget reservations fail; there is no automatic reauction. No M06B experiment result is asserted until the user runs this locally.
