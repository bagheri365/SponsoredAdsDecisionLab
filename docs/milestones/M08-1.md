# M08-1 — Deterministic synthetic evaluation harness

Status: Proposed; pending local verification.

Baseline: `4404d6a` (M07B-4).

## Scope

- Fixed, explicitly synthetic scored-candidate scenarios with relevance labels,
  budgets, eligibility, reserve prices, ties, and no-fill cases.
- Reuse `decide()` with fresh `BudgetLedger` per scenario and policy.
- Compare `first_price` and `score_second_price` without inference or settlement.
- Compute fill rate, synthetic relevance agreement, winning score, conditional
  CPC if clicked, budget reservation fraction, and no-fill breakdown.
- Canonical report and input SHA-256 fingerprints, overwrite-safe CLI.
- Regression tests for determinism, budget behavior, and invalid inputs.

## Local acceptance commands

```bash
pytest -q tests/test_m08_synthetic_evaluation.py
pytest -q
python -m sponsored_ads.m08_synthetic_evaluation --output artifacts/m08/m08_1_report.json
```

Run the CLI only when its output path does not already exist. Inspect its
reported hashes and compare repeat runs using distinct output paths.

## Interpretation

Synthetic relevance is a declared reference ordering, not observed click
relevance. The conditional CPC is not revenue. Independent ledgers per
scenario and policy preclude claims about long-run pacing or budget allocation.
