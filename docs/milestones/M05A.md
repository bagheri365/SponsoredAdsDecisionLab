# M05A — LightGBM feature contract and serving parity

## Deliverables

- Versioned, strict, JSON LightGBM preprocessing contract.
- Shared train/serve categorical encoding and ordered float32 transformation.
- `run()` persists `m1_lightgbm_static.contract.json` and
  `m2_lightgbm_intent.contract.json` alongside new booster files, with SHA-256
  hashes and contract paths in metrics.
- Explicit model/contract loader and prediction helper.
- Small deterministic parity, unseen-category, invalid-input and serialization tests.

## Reproduction

```bash
pytest -q
# Existing M03B CLI training can be rerun on M03A prepared train/validation files.
# Do not attempt serving old boosters lacking saved category dictionaries.
```

## Scope limits

No full-data retraining, retrieval-candidate feature construction, ranking
metrics, online-lift claims, or verified point-in-time histories. M03B SGD
logistic hashing is unchanged. Contract files may contain high-cardinality
identifiers and should remain in ignored local artifacts.
