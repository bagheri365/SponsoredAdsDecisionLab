# M07A-1 — Deterministic auction decision service

Status: Pending local verification.

## Scope

Expose a single synchronous interface over M06B-2 budget-aware admission. Inputs are already scored ad candidates, not raw features or an actual model inference response. Return explicit fill/no-fill and deterministic trace metadata. A fill reserves the maximum CPC bid but does not settle a click.

## Reproduce

```bash
pytest -q tests/test_m07a1_decision_service.py
pytest -q
git diff --check
```

## Example

```python
from sponsored_ads.models import AdRequest, AdCandidate
from sponsored_ads.budget_ledger import BudgetLedger
from sponsored_ads.decision_service import decide

ledger = BudgetLedger({'adv-a': 199, 'adv-b': 300})
response = decide(
    AdRequest('req-1', 'shopper-1'),
    [AdCandidate('a', 'adv-a', .2, 2), AdCandidate('b', 'adv-b', .1, 3)],
    ledger, policy='score_second_price', event_id='e1', reservation_id='r1',
)
assert response.status == 'filled'
assert response.outcome.ad_id == 'b'
assert response.trace.excluded_ad_ids == ('a',)
assert ledger.snapshot('adv-b').reserved_cents == 300
assert ledger.snapshot('adv-b').spent_cents == 0
```

## Non-goals

No production deployment, network API, end-to-end model scoring, pacing, event-driven settlement, or concurrent writers. The local full-suite test count is not asserted until run on the user's machine.
